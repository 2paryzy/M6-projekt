# F1 Odds Platform

## Beskrivelse
Dette projekt er udviklet som en del af kurset Design af IT-baserede systemer.
Der er udvalgt at lave en F1 betting hjemmeside.

## Funktioner
- Visning af Formel 1-kørere
- Oversigt over hold
- Odds-information
- Kontaktformular
- Konto/ Opret konto/ Login
- Indbetaling/ Udbetaling
- floating pop up viduer
